# Overview  

**목표**  
사내 CRM을 포함한 웹 기반 입력창에서 자주 쓰는 업무 문장을 자동으로 완성하거나 추천하여, 반복적이고 정형화된 업무 커뮤니케이션 효율을 높인다.

**형태**  
- 크롬 브라우저 확장 프로그램  
- 사내 CRM(웹 브라우저 기반) 텍스트 입력창에서 동작  
- LLM 모델(비추론): NAVER CLOVA HCX-005
- 데이터베이스 연동을 통한 템플릿 및 사용자 데이터 저장/공유

# Core Features  

| 기능명 | 설명 | 호출 방식 |
|--------|------|------------|
| 템플릿 자동완성 | 업무 템플릿(협조 요청 등) 자동 완성 | 키워드 (`/서버`, `/협조`) |
| 실시간 문장 추천 | 입력 중 문맥에 맞는 다음 문장 추천 | 실시간 입력 감지, 단축키(ex. TAB 키)를 눌러 적용 |
| 문구 학습 기반 추천 | 사용자/팀 단위 자주 쓰는 문구 추천 | 최근 사용 이력 분석 |
| 데이터 동기화 | 다양한 기기 간 사용자 템플릿 및 설정 동기화 | 로그인 시 자동 동기화 |
| 팀 공유 템플릿 | 조직/팀 단위로 템플릿 공유 및 관리 | 공유 템플릿 라이브러리 |

# User Experience  

**사용자 페르소나**
- 기업 CRM 시스템을 사용하는 사내 직원
- 반복적인 업무 커뮤니케이션이 필요한 업무 담당자
- 효율적인 문서 작성이 필요한 관리자
- 팀 간 일관된 메시지 작성이 필요한 조직 관리자

**주요 사용자 흐름**
1. 사용자가 CRM 입력창에서 텍스트 입력 시작
2. 키워드 입력 시 템플릿 자동완성 제안
3. 일반 텍스트 입력 시 문맥에 맞는 다음 문장 추천
4. 사용자가 추천 텍스트 수락 또는 계속 입력
5. 새로운 템플릿 생성 및 데이터베이스에 저장/공유

**UI/UX 고려사항**
- 침해적이지 않은 추천 UI (입력창 바로 아래 툴팁 형태 또는 일반 텍스트와 차별화된 형태)
- 키보드만으로 추천 선택/거부 가능
- 사용자 선호도에 따른 추천 빈도, 적용 도메인 조정 가능
- 사용자 계정 관리 및 동기화 설정 인터페이스

# Technical Architecture  

**시스템 구성요소**
- 브라우저 확장 프로그램 (Content Script, Background Script)
- 템플릿 매칭 엔진
- CLOVA Studio HCX-005 API 연동 모듈
- 추천 UI 컴포넌트
- 데이터베이스 연동 모듈
- 사용자/팀 데이터 관리 서비스
- 인증 및 권한 관리 모듈

**데이터 모델**
- 사용자: `{id, email, name, team_id, settings, created_at, updated_at}`
- 팀: `{id, name, admin_id, settings, created_at, updated_at}`
- 템플릿 데이터: `{id, creator_id, team_id, keyword, template_text, category, is_shared, usage_count, created_at, updated_at}`
- 사용자 설정: `{user_id, preferences, history_enabled, sync_enabled}`
- 사용 이력: `{id, user_id, text_fragment, context, timestamp, source_app}`

**API 및 통합**
- CLOVA Studio HCX-005 API: 문장 예측 및 추천
- 하이브리드 스토리지: 로컬 스토리지 + 원격 데이터베이스
- 백엔드 API: 사용자, 팀, 템플릿 및 이력 관리
- 인증 API: 사용자 인증 및 권한 관리
- 동기화 API: 크로스 디바이스 데이터 동기화

**인프라 요구사항**
- 클라이언트 측: Chrome Extension (Manifest v3)
- 서버 측: FastAPI 기반 백엔드 (사용자/팀/템플릿 관리)
- 데이터베이스: MongoDB/PostgreSQL (사용자/팀/템플릿 데이터 저장)
- 인증: JWT 기반 인증 시스템

# Development Roadmap  

**MVP (필수 구현 요소)**
- 크롬 확장 프로그램 기본 구조 설계 및 배포
- `/서버`, `/협조` 등 키워드 기반 템플릿 매칭 기능
- HCX-005 API 연동을 통한 실시간 문장 예측
- 기본 추천 UI: 팝업 및 입력창 근처 추천 문구 노출

- 고급 템플릿 등록 및 편집 UI
- 사내 Works, Gmail, Slack 등 추가 시스템 연동
- 오프라인 모드 및 사내망 보안 최적화
- 조직 관리 페이지 (문구 공유 및 관리)
- 고급 데이터 분석 및 추천 알고리즘 (DB 기반)
- 팀 간 템플릿 공유 및 협업 기능
- 백업 및 동기화 메커니즘

# Risks and Mitigations  

**기술적 도전 과제**
- **위험**: 다양한 CRM 시스템의 입력창 구조 차이로 인한 호환성 문제
  - **완화 방안**: 범용적인 DOM 선택자 사용 및 확장 가능한 어댑터 패턴 적용

- **위험**: API 호출 지연으로 인한 사용자 경험 저하
  - **완화 방안**: 로컬 캐싱 및 예측적 API 호출 최적화

**데이터베이스 관련 위험**
- **위험**: 사용자 데이터 프라이버시 및 보안 문제
  - **완화 방안**: 암호화 저장, 접근 제어, GDPR 등 규정 준수

- **위험**: 오프라인 상태에서의 기능 제한
  - **완화 방안**: 로컬 캐싱 및 동기화 메커니즘 구현

**MVP 범위 관련**
- **위험**: 초기 템플릿 품질이 사용자 기대치에 미치지 못할 가능성
  - **완화 방안**: 가장 자주 사용되는 템플릿에 집중하고 사용자 피드백 기반 지속 개선

- **위험**: 개인정보 및 민감한 업무 정보 처리 우려
  - **완화 방안**: 입력 내용의 민감도 고려한 LLM 호출 조건 설정 및 옵트인 방식 적용

**자원 제약**
- **위험**: 다양한 웹 애플리케이션 지원에 필요한 개발 리소스 제한
  - **완화 방안**: 우선순위가 높은 핵심 CRM 시스템부터 단계적 지원 확대
